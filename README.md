♻️ Recycling Management System

A web-based application designed to manage recycling operations, including bale tracking, material categories, sales data, reporting, and role-based access for administrators and technicians.

📌 Overview

The Recycling Management System streamlines recycling facility operations by providing:

Centralized data entry for recycling bales and sales

Role-based access control for administrators and technicians

Accurate reporting and analytics

Secure, reliable, and user-friendly workflows

This system supports operational transparency, data accuracy, and performance tracking across materials, technicians, and vendors.

👥 User Roles
Administrator

Administrators have full system access, including:

User & access management

Recycling material/category management

Bale creation and editing

Sales data entry and management

Reporting and analytics (tabular & graphical)

Data exports (CSV/XLSX)

Technician

Technicians have limited access, including:

Bale data entry

Editing only their own bale records

Viewing relevant data needed for operations

⚙️ Core Features
🔐 Security & Access Control

Role-based permissions (Admin vs Technician)

User activation/deactivation

Ownership-based editing restrictions

♻️ Recycling Operations

Material category management (active/inactive)

Bale data entry and editing

Vendor and weight tracking

Bale-to-vendor weight variance analysis

💰 Sales Management

Multi-line item sales entries

Optional price-per-ton input

Automatic total calculations

Time-to-sale metrics (min/avg/max)

📊 Reporting & Analytics

Date-range reports

Monthly & annual trend graphs

Material performance tracking

CSV/XLSX export support

Reconciled on-screen and exported totals

🚀 Performance & Reliability

Optimized workflows for daily operations

Consistent system response under typical load

Reliable data persistence

🧪 Testing & Validation

The system has been evaluated using scenario-based testing, including:

User creation and deactivation

Category lifecycle validation

Cross-user edit restrictions

Sales total verification

Report accuracy and exports

Weight variance detection (> ±2%)

Time-to-sale calculations

🛠️ Tech Stack 

Frontend: HTML, CSS, JavaScript 

Backend: Node.js / Java / Python

Database: MySQL / PostgreSQL / MongoDB

Authentication: Role-based access control

Hosting: Local / Cloud-based
